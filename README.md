# C++ Data Analysis Tool

> **Learning project** — built as coursework / for learning. Kept here as a reference and a record of the work.

A high-performance statistical tool for numerical data analysis.

## Overview
This project demonstrates the application of C++ in Data Science. It processes datasets to compute central tendency metrics (Mean and Median) with $O(n \log n)$ efficiency.

## Key Features
- **Statistical Computation**: Manual implementation of mean and median logic.
- **STL Optimization**: Utilizes `std::vector`, `std::accumulate`, and `std::sort`.
- **Object-Oriented**: Encapsulated logic within a `DataAnalyzer` class.

## How to Run
1. Compile: `g++ main.cpp -o data_tool`
2. Run: `./data_tool`
